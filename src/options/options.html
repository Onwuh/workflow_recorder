Einstellungen

Zugriff auf Websites

Die Erweiterung nimmt nur auf Websites auf, die Sie freigegeben haben. Beim ersten Start auf einer neuen Website fragt der Browser einmal nach.

    Noch keine Website freigegeben.

    Aufnahme

    Automatisch geschwärzte Felder

    Technische Feldnamen aus Odoo (Attribut name der Feld-Widgets und Listenspalten), einer pro Zeile. E-Mail-, Telefon- und Passwortfelder werden auf allen Seiten immer geschwärzt.

    Export

    Kurzbefehl

    Aufnahme starten und beenden: . Ändern lässt er sich in den Tastenkürzel-Einstellungen des Browsers.

    Datenschutz

    Alle Anleitungen und Screenshots bleiben in diesem Browser. Die Erweiterung sendet nichts an Server, nutzt keine Cloud-KI und lädt keine fremden Ressourcen.
